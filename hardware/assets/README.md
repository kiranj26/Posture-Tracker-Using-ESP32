# Hardware Assets

Screenshots and renders for use in README files.

## How to capture these from KiCad

### PCB 3D render (`pcb_v2_3d.png`)
1. Open `hardware/kicad/posture_tracker_v2/posture_tracker_v2/posture_tracker_v2.kicad_pcb`
2. View → 3D Viewer
3. Rotate to a good angle (isometric top-left works well)
4. Screenshot → save as `hardware/assets/pcb_v2_3d.png`

### PCB top view (`pcb_v2_top.png`)
1. In the PCB Editor, press `Home` to fit board in view
2. Ensure F.Cu, F.Silkscreen, F.Mask, Edge.Cuts layers are visible
3. Screenshot → save as `hardware/assets/pcb_v2_top.png`

### Schematic (`schematic_v2.png`)
1. Open `posture_tracker_v2.kicad_sch` in KiCad Schematic Editor
2. File → Export → Export as Image
3. Format: PNG, resolution: 150 dpi
4. Save as `hardware/assets/schematic_v2.png`
